The former baseline did not select its named modes: VIZ_EVERY=100000 delayed
leaving the initial ridge. The corrected harness uses a 1-second first switch,
waits for the requested mode in the perf log, then warms up beyond the morph.
With a single requested mode it stays there for the rest of the sample.

Both additions use 64 dots (or the existing base shape's larger slot count),
fixed O(n) topology, and O(n) geometry. Aurora has 84 links; Prism has 124.
They reuse the existing palette, sparse glow sprite, quantized stroke batches,
framebuffer, dirty cells, onset pulses, treble sparkles and morph pipeline.
No new full-screen rendering passes, neighbour searches, or growing histories.
