# UI previews

**Start with [current/README.md](current/README.md).** That is the current design
reference for the TV app and phone remote. It records how the images were
captured and which source produced them.

- `current/`: current app screenshots with sample data and source manifests.
- `archive/`: historical UI screenshots. Never use them to infer the present UI.
- `circuit-*` and `viz-*`: ambient-effect demonstrations and path diagnostics,
  not references for menus or phone controls.
- `sample-recommendations.json`: synthetic preview content, not playback history.

When the UI changes, refresh the current captures, update their manifests and
review the resulting images. Do not promote an old capture based on its filename
(`live`, `final` or `redesign` does not mean current).
