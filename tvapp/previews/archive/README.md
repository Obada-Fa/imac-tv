# Historical UI screenshots — not the current design

These captures predate the current shared glass UI. They are retained as history,
not deleted. Names such as `final-live` and `redesign-live` described an older
point in development and do not indicate the current installed app.

- `legacy-ui/`: early TV and phone designs, including the old Stremio/VLC launcher.
- `menu-refresh/`: the earlier menu refresh, before `widgets/glass.py` and
  `widgets/chrome.py` unified the menus on 26 October 2026.

Use [the current gallery](../current/README.md) and inspect the actual app code
before making visual changes.
